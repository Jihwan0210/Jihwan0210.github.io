기술 스택

각 기술이 무슨 일을 하는 도구인지 함께 적었습니다.

프로젝트에서 직접 써 보고, 왜 골랐는지와 어디까지 되는지 설명할 수 있는 도구들입니다.

서버 개발 화면 뒤에서 데이터를 처리하는 부분
Java
서버 프로그램을 만드는 프로그래밍 언어. 국내 기업에서 가장 널리 쓰입니다.
Spring Boot
Java로 서버를 빠르게 만들게 도와주는 도구 모음. 요청을 받고 처리해 결과를 돌려주는 구조를 만듭니다.
Spring Security
로그인 확인과 권한 관리. "이 사람이 맞는지", "이 기능을 써도 되는 사람인지"를 검사합니다.
Spring Data JPA
프로그램의 데이터를 데이터베이스에 저장하고 꺼내 오는 연결 도구.
MyBatis
데이터베이스 명령문을 직접 써서 다루는 방식의 도구. (교육 과정에서 실습)
데이터 저장 정보를 쌓고 찾아오는 부분
MySQL · MariaDB
회원·상품·주문 같은 정보를 표 형태로 보관하는 데이터베이스. 어떤 표를 만들지 설계하고, 원하는 정보를 찾아내는 명령문을 씁니다.
Redis
잠깐만 필요한 정보를 빠르게 보관하는 저장소. 정해 둔 시간이 지나면 저절로 지워집니다.
배포 · 협업 만든 것을 인터넷에 올리고 함께 작업하는 부분
AWS EC2 · S3
아마존이 빌려주는 인터넷 서버와 파일 보관소. 만든 프로그램을 여기에 올려 누구나 접속할 수 있게 합니다.
Docker · Linux
"내 컴퓨터에선 되는데"를 막는 도구. 프로그램과 실행 환경을 통째로 묶어 어느 서버에서든 똑같이 돌아가게 합니다.
Git · GitHub
코드의 변경 기록을 남기고 여러 명이 겹치지 않게 함께 작업하는 도구. 서로의 코드를 확인하고 합칩니다.
외부 서비스 연결 다른 회사 기능을 가져다 쓰는 부분
REST API · Swagger
화면(앱·웹)과 서버가 정보를 주고받는 약속을 정하고, 그 약속을 문서로 만들어 팀에 공유합니다.
TossPayments
실제 카드 결제를 처리하는 외부 결제 서비스. 매달 자동으로 빠져나가는 구독 결제를 연결했습니다.
AI(LLM) 연동
ChatGPT 같은 AI를 서비스 안에서 불러 쓰고, AI가 돌려준 답을 화면에 쓸 수 있는 형태로 정리합니다.

그 외에 화면을 만드는 도구(React·TypeScript·Thymeleaf)와 다른 언어(PHP·Laravel·Python·R)도 학습·개인 프로젝트에서 사용해 봤습니다.

01

COGI

AI 코드 리뷰 SaaS · 4인 팀

개발자가 작성한 코드를 AI가 대신 검토해 주고, 자주 반복되는 실수를 팀·개인별 통계로 보여 주는 월 구독 서비스입니다.

맡은 일가입 전 무료 체험 · 구독 결제 · 운영자용 관리 기능
흐름사용자 화면 → 로그인·체험 확인 → 결제·관리 기능 → 데이터 저장·카드 결제
  • 매달 자동으로 결제되는 구독 기능 전체를 만들었습니다. 요금제 변경, 해지 예약, 사용량 차감까지 포함합니다.
  • 매일 밤 구독료를 한꺼번에 청구할 때, 한 사람의 결제가 실패하면 나머지 사람들의 결제까지 취소되던 문제를 찾아 사람별로 따로 처리되도록 고쳤습니다.
  • 가입하지 않아도 AI 리뷰를 써 볼 수 있게 열되, AI 사용료가 무제한으로 나가지 않도록 24시간에 3번까지만 쓰도록 제한했습니다.

02

읽고 (Ilgo)

AI 배리어프리 서비스 · 6인 팀 · 해커톤 3등

고지서나 안내문처럼 알아보기 어려운 문서를 사진으로 찍으면, AI가 쉬운 한국어나 영어로 풀어서 알려 주는 앱입니다. 6인 팀에서 앱 뒤쪽 서버 전체를 맡았습니다.

맡은 일서버 개발 전체 · 로그인 · AI 연결 · 앱과의 약속 문서
흐름문서 사진 촬영 → 로그인 확인 → AI 분석 요청 → 정해진 형태로 정리해 전달
  • AI는 답변 형태가 매번 달라 앱에서 화면을 만들 수 없었습니다. 서버에서 설명 · 위험도 · 핵심 내용 · 해야 할 일 네 칸으로 정리해 내려보내, 앱이 화면 하나로 처리할 수 있게 했습니다.
  • 로그인 확인 방식과 오류 처리 규칙을 한곳에 모아, 기능을 새로 추가해도 같은 방식이 적용되게 했습니다. 한 사람이 1분에 20번까지만 AI를 부를 수 있도록 제한도 걸었습니다.
  • 서버와 앱이 주고받을 내용을 문서로 먼저 공유해 4일이라는 짧은 기간에 서버와 앱을 동시에 개발했고, AI Re-Local 해커톤 3등(선도상)을 받았습니다.

03

PotatoChip

못난이 농산물 마켓 · 5인 팀 팀장

모양이 예쁘지 않다는 이유로 버려지는 농산물을 농가가 소비자에게 직접 파는 온라인 장터입니다. 5인 팀의 팀장이자 상품·장바구니 담당이었습니다.

맡은 일팀장 · 상품 등록과 장바구니 기능
흐름사진 올리면 AI가 설명 초안 작성 → 본인 상품만 수정 가능 → 담은 가격 그대로 유지
  • 농가 판매자가 상품 설명 쓰기를 어려워해 등록을 포기하는 경우가 많았습니다. 사진만 올리면 AI가 제목과 설명 초안을 써 주고, 판매자는 확인·수정만 하면 되게 만들었습니다.
  • 장바구니에 담은 뒤 판매자가 가격을 올리면 결제 금액이 몰래 바뀌던 문제가 있었습니다. 담은 순간의 가격을 따로 저장해 두는 방식으로 바꿔 금액이 흔들리지 않게 했습니다.
  • 팀원들이 작업을 오래 쌓아 뒀다가 한꺼번에 합치면서 서로의 코드가 충돌하고 사라지는 사고가 있었습니다. 작게 자주 합치는 규칙을 정해 해결했습니다.
