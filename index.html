COGI

AI 코드 리뷰 SaaS · 4인 팀 · 진행 중

GitHub Pull Request를 가져와 AI가 코드를 리뷰하고, 팀과 개인의 약점 패턴을 통계로 추적하는 구독형 SaaS입니다.

역할비로그인 체험 · 구독 결제 · 관리자 백엔드
흐름React → JWT · Guest → 결제 · 관리자 도메인 → MariaDB · Redis · Toss
  • 결제·구독 도메인 전체를 단독 설계·구현했습니다. Toss 빌링키 정기결제, 플랜 변경·해지 예약, 크레딧 차감까지 담당했습니다.
  • 자정 배치를 구독 건별 트랜잭션으로 나눠, 한 건의 결제 실패가 나머지 구독자 청구를 멈추지 않도록 격리했습니다.
  • Redis TTL 카운터로 비로그인 체험을 열면서 AI 호출 상한을 24시간 3회로 고정하고, 관리자 통계의 N+1 쿼리를 IN 조회 1회로 줄였습니다.

읽고 (Ilgo)

AI 배리어프리 서비스 · 6인 팀 · 해커톤 3등

고지서·안내문처럼 어려운 생활 문서를 사진으로 찍으면 AI가 쉬운 한국어나 영어로 풀어주는 배리어프리 서비스입니다. 6인 팀에서 백엔드 API 서버 전체를 맡았습니다.

역할백엔드 API · 인증과 AI 연동, 문서화
흐름문서 이미지 → JWT 인증 → AI 게이트웨이 → 구조화 응답
  • 형태가 매번 달라지는 AI 응답을 설명·위험도·핵심 카드·할 일의 고정 스키마로 파싱해, 프론트가 화면 규격 하나로 붙일 수 있게 했습니다.
  • JWT Stateless 인증과 전역 예외 처리·레이트 리밋 공통 계층을 설계하고, 인증·분석 테스트 코드를 작성했습니다.
  • Swagger로 API 명세를 공유해 3일짜리 해커톤에서 프론트와 병렬 개발했고, AI Re-Local 해커톤 3등(선도상)을 받았습니다.
