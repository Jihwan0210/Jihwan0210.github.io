기술 스택

각 기술이 무슨 일을 하는 도구인지 함께 적었습니다.

프로젝트에서 직접 써 보고, 왜 골랐는지와 어디까지 되는지 설명할 수 있는 도구들입니다.

서버 개발 화면 뒤에서 데이터를 처리하는 부분
Java
서버 프로그램을 만드는 프로그래밍 언어. 국내 기업에서 가장 널리 쓰입니다.
Spring Boot
Java로 서버를 빠르게 만들게 도와주는 도구 모음. 요청을 받고 처리해 결과를 돌려주는 구조를 만듭니다.
Spring Security
로그인 확인과 권한 관리. "이 사람이 맞는지", "이 기능을 써도 되는 사람인지"를 검사합니다.
Spring Data JPA
프로그램의 데이터를 데이터베이스에 저장하고 꺼내 오는 연결 도구.
MyBatis
데이터베이스 명령문을 직접 써서 다루는 방식의 도구. (교육 과정에서 실습)
데이터 저장 정보를 쌓고 찾아오는 부분
MySQL · MariaDB
회원·상품·주문 같은 정보를 표 형태로 보관하는 데이터베이스. 어떤 표를 만들지 설계하고, 원하는 정보를 찾아내는 명령문을 씁니다.
PostgreSQL
MySQL과 같은 표 형태의 데이터베이스. 읽고 프로젝트에서 사용했습니다.
Redis
잠깐만 필요한 정보를 빠르게 보관하는 저장소. 정해 둔 시간이 지나면 저절로 지워집니다.
배포 · 협업 만든 것을 인터넷에 올리고 함께 작업하는 부분
AWS EC2 · S3
아마존이 빌려주는 인터넷 서버와 파일 보관소. 만든 프로그램을 여기에 올려 누구나 접속할 수 있게 합니다.
Docker · Linux
"내 컴퓨터에선 되는데"를 막는 도구. 프로그램과 실행 환경을 통째로 묶어 어느 서버에서든 똑같이 돌아가게 합니다.
Git · GitHub
코드의 변경 기록을 남기고 여러 명이 겹치지 않게 함께 작업하는 도구. 서로의 코드를 확인하고 합칩니다.
외부 서비스 연결 다른 회사 기능을 가져다 쓰는 부분
REST API · Swagger
화면(앱·웹)과 서버가 정보를 주고받는 약속을 정하고, 그 약속을 문서로 만들어 팀에 공유합니다.
TossPayments
실제 카드 결제를 처리하는 외부 결제 서비스. 매달 자동으로 빠져나가는 구독 결제를 연결했습니다.
AI(LLM) 연동
ChatGPT 같은 AI를 서비스 안에서 불러 쓰고, AI가 돌려준 답을 화면에 쓸 수 있는 형태로 정리합니다.

그 외에 화면을 만드는 도구(React·TypeScript·Thymeleaf)와 다른 언어(PHP·Laravel·Python·R)도 학습·개인 프로젝트에서 사용해 봤습니다.

COGI

맡은 일결제·구독 · 비로그인 체험 · 관리자 백엔드
흐름결제 시도 DB 기록 → 토스 청구 → 결과 불명이면 조회로 확정 → 확실한 거절만 강등
  • TossPayments 빌링키 기반 정기 결제와 플랜 변경·해지 예약·크레딧 차감을 담당했습니다.
  • 정기결제 타임아웃 시 토스 조회로 승인 여부를 확정해, 장애 테스트에서 잘못된 강등·중복 청구 0건을 확인했습니다.
  • 비로그인 체험 횟수를 Redis 스크립트로 원자 처리해 동시 40건 중 3건만 허용했습니다.
  • 긴급 공지 메일 작업을 DB에 저장해 서버 재시작 후에도 대기 작업이 남게 했습니다.

읽고 (Ilgo)

AI 배리어프리 문서 해석 · 6인 팀 · 해커톤 선도상 3등 · 2026.06.30~07.03

고지서·안내문 등 생활 문서 사진을 쉬운 한국어·영어 설명으로 바꾸는 서비스입니다. 6인 팀에서 백엔드 API 서버를 혼자 맡았습니다.

맡은 일로그인·권한 · 문서 분석 · 공통 처리 · 테스트
흐름문서 사진 → JWT 검증 → AI 분석 → 고정 스키마 DTO로 파싱 → 앱 전달
  • 형태가 매번 달라지는 AI 응답을 요약·위험도·핵심 카드·할 일의 고정 스키마로 파싱하고 실패 응답 규격을 정했습니다.
  • 쿠키를 다루지 않는 Flutter 앱에 맞춰 JWT 인증을 적용하고, 예외 처리·요청 제한을 공통 계층으로 묶었습니다.
  • 사용자당 분당 20회 레이트 리밋을 적용해 외부 AI 호출 남용을 막았습니다.
  • 인증·분석·문서 생성 기능에 40개 테스트 케이스를 작성해 회귀 검증 기반을 만들었습니다.

03

PotatoChip

못난이 농작물 마켓플레이스 · 5인 팀 팀장 · 2026.05~06

상품성이 낮다는 이유로 버려지는 농작물을 판매자와 구매자가 직접 거래하는 서비스입니다. 5인 팀의 팀장이자 상품 도메인 담당이었습니다.

맡은 일상품·재고 · 장바구니 · 배포 · 팀 리딩
흐름조건부 UPDATE 재고 차감 → 랭킹 1분 주기 분리 → currentPrice() 통일
  • 상품 도메인과 판매자 소유권 검증을 구현하고, 상품 사진에서 제목·설명 초안을 채우는 기능을 개발했습니다.
  • 재고 초과 판매를 조건부 UPDATE로 막아 1,722건에서 0건으로 줄였습니다.
  • 판매 랭킹 계산을 주문과 분리해 주문 처리 시간을 1,240ms에서 49ms로 줄였습니다.
  • 끝난 할인이 할인가로 팔리던 문제를 현재가 계산 하나로 통일해 해결했습니다.
  • 파일 저장을 인터페이스로 분리해 개발 환경은 로컬 디스크, 운영 환경은 S3를 쓰도록 하고 Docker로 EC2에 배포했습니다.
