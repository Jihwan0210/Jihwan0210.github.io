#내 역할

  • JWT 기반 인증·인가 설계
  • 외부 AI 게이트웨이 연동 문서 분석 API
  • API 문서화와 테스트로 안정성 확보

#구현 흐름

문서 이미지/텍스트› JWT 인증› AI 게이트웨이› 구조화 응답› 커서 페이지네이션 조회

#주요 구현

  • 요청별 토큰 검증 필터, Stateless 정책, 경로별 접근 제어
  • 문서 분석 API(응답을 설명·위험도·핵심 카드·할 일 구조로 파싱)
  • 이미지 업로드(multipart)와 JSON 양쪽 요청 지원
  • 커서 기반 페이지네이션
  • 전역 예외 처리와 요청 레이트 리밋
  • Swagger(OpenAPI) 문서 자동화로 프론트와 규격 공유
  • 인증·분석·문서 생성 테스트 작성
