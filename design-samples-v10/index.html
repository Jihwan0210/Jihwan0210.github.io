#문제 해결

AS-IS 문제 상황에서 TO-BE 개선까지. git diff처럼 읽어보세요.

장바구니 가격 정합성

PotatoChip
-AS-IS 상품 가격이 바뀌면 이미 담긴 장바구니 금액까지 함께 변했습니다. 장바구니가 상품 엔티티의 현재 가격을 직접 참조했기 때문입니다.
+TO-BE CartItem에 담은 시점 가격을 스냅샷으로 저장. 이후 가격이 바뀌어도 장바구니와 주문 금액이 일관되게 유지됩니다.

정기결제 배치 안정성

COGI · Payment
-AS-IS 한 건의 결제 실패가 배치 전체를 중단시킬 위험이 있었습니다.
+TO-BE 결제를 건별 @Transactional로 분리하고 예외를 격리. 실패 건만 FREE로 강등하고 나머지 청구는 계속됩니다.

비로그인 남용 방지

COGI · Guest
-AS-IS 계정 없이 AI 리뷰를 무제한 호출할 수 있어 비용과 남용 위험이 있었습니다.
+TO-BE guest_token 쿠키와 Redis 카운터로 24시간 3회 제한. 첫 요청에만 TTL을 걸어 첫 사용 기준으로 리셋됩니다.

관리자 통계 N+1

COGI · Admin
-AS-IS 사용량 로그마다 사용자 닉네임을 개별 조회해 N+1 쿼리가 발생했습니다.
+TO-BE userId를 모아 IN 조회 한 번으로 닉네임을 매핑해 쿼리 수를 줄였습니다.
