About 프로젝트 기술

저는 Java와 Spring으로 서비스의 뒷단을 만드는 백엔드 개발자입니다. 지금은 팀 프로젝트 COGI에서 비로그인 체험, 구독 결제, 관리자 백엔드를 맡고 있습니다.

PHP로 처음 웹을 만들고 Laravel로 구조를 익힌 뒤 Spring으로 옮겼습니다. PotatoChip에서는 팀장으로 상품 도메인을, 읽고에서는 인증과 AI 연동을 맡으며 지금에 이르렀습니다.

문제가 생기면 증상만 고치기보다 데이터 흐름과 구조를 따라가 원인을 잡습니다. 코드는 github.com/Jihwan0210에 있습니다.

COGI

AI 코드 리뷰 SaaS · 팀 · 진행 중

GitHub PR을 가져와 AI가 코드를 리뷰하고, 이슈와 성장 추이를 팀 단위로 관리하는 서비스입니다. 저는 서비스로 들어오는 세 관문, 비로그인 체험, 구독 결제, 관리자를 맡았습니다.

A · GUEST

비로그인 체험

guest_token 쿠키(24h)로 익명 식별하고, Redis 카운터로 체험 3회를 제한했습니다. 첫 요청에만 TTL을 걸어 첫 사용 기준으로 리셋되게 했고, 초과 시 403.

B · PAYMENT

구독 결제

Toss 빌링키로 매일 자정 건별 트랜잭션 청구. 한 건 실패가 배치를 멈추지 않게 격리하고, 실패 건만 FREE로 강등. 소유·중복·약관을 먼저 검증합니다.

C · ADMIN

관리자

ROLE_ADMIN으로 입구를 막고, 회원·공지·약관·AI 사용량을 다룹니다. 공지는 @Async 메일 발송, 통계는 IN 조회로 N+1을 피했습니다.
