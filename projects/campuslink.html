주요 구현

  • React 18과 TypeScript 기반 SPA를 설계하고 전체 개발을 진행했습니다.
  • Context API(AuthContext)로 전역 로그인 상태를 관리했습니다.
  • sessionStorage와 연동해 새로고침 후에도 세션이 유지되도록 했습니다.
  • 작성자 여부를 판별해 권한을 분기했습니다.
  • Vercel과 AWS Amplify로 배포했습니다.
