못난이 농산물을 거래하는 마켓플레이스입니다. 팀장이자 상품 도메인 담당으로 프로젝트 전반을 주도했습니다.

내 역할

팀장이자 상품 도메인 오너로, 팀을 이끌면서 상품과 장바구니 도메인을 직접 설계하고 구현했습니다.

  • 상품 도메인 상품 CRUD와 판매자 전용 권한, 카테고리·키워드 필터를 설계하고 구현했습니다.
  • 장바구니 담은 시점의 가격을 유지하는 가격 스냅샷 CartItem 구조를 설계했습니다.
  • 부가 기능 Kakao Map 픽업 위치, 즉시 구매 흐름, 기간별 판매 랭킹을 구현했습니다.
  • 팀 리딩 develop·feature 브랜치 전략과 PR 코드 리뷰를 운영하고, 일정과 문서를 총괄했습니다.

주요 구현

  • 상품 CRUD와 판매자 전용 권한 제어를 구현했습니다.
  • 카테고리·키워드 필터를 Thymeleaf 서버사이드 렌더링으로 구현했습니다.
  • Kakao Map API를 연동해 상품별 픽업 위치를 보여줍니다.
  • 가격 스냅샷 기반 CartItem 구조로 담은 시점의 가격을 유지하도록 설계했습니다.
  • 즉시 구매 흐름과 장바구니 요약 금액 계산을 구현했습니다.
  • 기간별 판매 랭킹을 집계했습니다.
  • develop·feature 브랜치 전략을 세우고 PR 코드 리뷰를 운영했습니다.
