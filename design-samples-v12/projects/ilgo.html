읽고 (Ilgo)

어려운 생활 문서를 사진으로 찍으면 AI가 쉬운 한국어 또는 영어로 풀어주는 배리어프리 서비스입니다. 백엔드 API 서버를 담당했습니다.

내 역할

  • 인증·인가 JWT 기반 인증과 인가를 설계했습니다.
  • 문서 분석 API 외부 AI 게이트웨이와 연동하는 문서 분석 API를 구현했습니다.
  • 안정성 문서화와 테스트로 API 안정성을 확보했습니다.

구현 흐름

문서 이미지› JWT 인증› AI 게이트웨이› 구조화 응답› 커서 페이지네이션 조회

주요 구현

  • 요청별 Authorization 토큰을 검증하는 필터를 두고, Stateless 정책과 경로별 접근 제어를 적용했습니다.
  • 문서 분석 API에서 AI 게이트웨이의 응답을 설명·위험도·핵심 카드·할 일 구조로 파싱했습니다.
  • 이미지 업로드(multipart)와 JSON 요청을 모두 지원하도록 설계했습니다.
  • 목록 조회에 커서 기반 페이지네이션을 적용했습니다.
  • 전역 예외 처리와 요청 레이트 리밋을 두었습니다.
  • Swagger 문서를 자동화해 프론트와 API 규격을 공유했습니다.
  • 인증, 분석, 문서 생성에 대한 테스트를 작성했습니다.
